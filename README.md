# Дастурамал: сатҳҳои нав (diffspot-levels)

Ин репозиторий сатҳҳои навро барои бозиҳои **DiffSpot** ва **Пазл** нигоҳ медорад.

- 50 сатҳи аввал **дар дохили барнома** ҳастанд (бе интернет кор мекунанд).
- Сатҳҳои **51, 52, …** — аз ҳамин ҷо гирифта мешаванд.

Сатҳи навро ин ҷо бор кунед — он дар ҳарду бозӣ пайдо мешавад. Нашри версияи нав дар Google Play лозим **нест**.

---

## Сохтани репозиторий (як бор)

1. Дар GitHub: **+** (боло, рост) → **New repository**.
2. **Repository name:** `diffspot-levels` — маҳз ҳамин ном (барнома онро меҷӯяд).
3. **Public** — ҳатман оммавӣ (CDN-и jsDelivr танҳо бо репозиторийҳои оммавӣ кор мекунад).
4. **Create repository**.

---

## Файлҳо

```
diffspot-levels/
├── levels.json      ← рӯйхати сатҳҳои нав
├── level_51.webp    ← як файл барои ҳар сатҳ (ҳарду қисм болову поён)
├── level_52.webp
└── README.md        ← ҳамин дастурамал
```

Ҳар сатҳ — **як файл**. Он ҳам барои DiffSpot (ду қисм) ва ҳам барои Пазл (қисми болоӣ) кифоя аст.

Расмҳои аслӣ (`level_51_a`, `level_51_b`) ин ҷо бор **намешаванд** — онҳо дар компютер, дар папкаи `levels_src` мемонанд.

---

## Илова кардани сатҳи нав

### Дар компютер

1. Ду расмро аз ChatGPT ба `D:\AndroidStudioProjects\diffspot\levels_src\` гузоред:
   `level_51_a.webp` (асл) ва `level_51_b.webp` (бо фарқиятҳо).
2. Скриптро ронед:
   ```
   powershell -ExecutionPolicy Bypass -File tools\pack_levels.ps1
   ```
3. Дар охир бояд **«OK: ҳамаи сатҳҳо дурустанд»** нависад.
   Агар «ХАТО» бошад — расмҳои чорчӯбадорро дар `app\build\level-check\` бинед ва расми `_b`-ро аз нав созед.
4. Файлҳои тайёр дар папкаи **`D:\AndroidStudioProjects\diffspot\github_levels\`** пайдо мешаванд.

### Дар GitHub

5. Репозиторийи `diffspot-levels`-ро кушоед → **Add file → Upload files**.
6. Аз папкаи `github_levels` инҳоро кашед:
   - файлҳои **нави** `level_….webp`;
   - **`levels.json`** (ҳамеша — он рӯйхатро нигоҳ медорад).
7. **Commit changes**.

Тамом. Бозиҳо рӯйхати навро то **6 соат** пас мегиранд.

---

## ⚠️ Қоидаҳои муҳим

### 1. Сатҳҳоро танҳо ба ОХИР илова кунед

Ситораҳои бозингар ба **рақами сатҳ** вобастаанд. Агар сатҳро дар мобайн илова ё нест кунед, рақамҳо иваз мешаванд ва ситораҳои ҳама бозингарон ба сатҳҳои дигар мегузаранд.

- ✅ Сатҳи навро ба охир илова кардан (`pack_levels.ps1` худаш ҳамин тавр мекунад).
- ❌ Сатҳро аз `levels.json` нест кардан.
- ❌ Тартиби сатрҳоро дар `levels.json` дастӣ иваз кардан.
- ❌ Файли сатҳи нашршударо иваз кардан ё номашро тағйир додан.

### 2. Расми сатҳи нашршударо иваз накунед

Бозиҳо расми ҳар сатҳро **як бор** бор мекунанд ва дар телефон нигоҳ медоранд. Агар файлро бо ҳамон ном иваз кунед, бозингарон расми кӯҳнаро мебинанд.

Агар сатҳ бад бошад — онро бо **сатҳи нав** (рақами нав) иваз кунед ва сатҳи кӯҳнаро монед.

### 3. Номи файлҳо

Бо ҳарфҳои лотинии хурд, бе фосила: `level_51`, `level_52`, … Рақамгузории пайдарпайро нигоҳ доред.

## Бозиҳо сатҳҳоро чӣ тавр мегиранд?

- **Рӯйхат** (`levels.json`) — ҳангоми кушодани бозӣ, на зиёда аз як бор дар 6 соат.
- **Расми сатҳ** — танҳо вақте ки бозингар он сатҳро мекушояд (ё сатҳ дар рӯйхат кушода мешавад). Баъд дар телефон нигоҳ дошта мешавад ва бе интернет ҳам кор мекунад.
- Расмҳо тавассути **jsDelivr** (CDN-и ройгон) дода мешаванд — тез ва бе маҳдудияти трафики GitHub Pages.
- Бе интернет сатҳи нави ҳанӯз боркарданашуда кушода намешавад ва бозӣ мегӯяд: «Интернетро санҷед».
